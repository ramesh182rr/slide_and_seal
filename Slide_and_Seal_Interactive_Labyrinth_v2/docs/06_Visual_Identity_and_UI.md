# 06 — Visual Identity and High-End UI System

## 1. Art direction

Premium dark sci-fi mechanical architecture. Combine ancient monumental structures with precise futuristic mechanisms. The world should feel tactile, mysterious and engineered.

## 3. Material language

- Dark brushed metal.
- Beveled stone and machined edges.
- Emissive inlays for energy paths.
- Glass/crystal for the core.
- Restrained roughness variation.
- Portal materials with layered animated shader effects.
- Amber/white status lights for mechanical systems.

## 4. UI quality bar

Avoid default engine-looking UI. Build a custom design system:
- Distinctive display and body typography.
- Consistent spacing scale.
- Custom buttons and segmented controls.
- Carefully layered panels.
- Restrained glass/translucency.
- Subtle metallic borders.
- Clear focus/pressed/disabled states.
- Purpose-built icons.
- Motion language shared across screens.

## 6. World selection

Use seven miniature 3D dioramas. Each world has:
- Distinct silhouette.
- Dominant material and color accent.
- A landmark structure.
- A portal/seal motif.
- A short title and one-line theme.

## 7. Typography

Choose a highly legible modern geometric sans-serif for UI. Use a distinctive display face for titles only. Verify font licenses and Android rendering. Avoid tiny all-caps labels for critical controls.

## 8. Accessibility

- Color-independent icons.
- High-contrast mode.
- Adjustable UI scale.
- Reduced motion.
- Adjustable haptics/audio.
- Clear selected/active states.
- No essential information communicated only by glow or color.

## 9. Asset guidance

Generated images in `assets/` are concept references. Rebuild actual UI with native Godot controls and actual game objects with licensed or original meshes. Do not crop concept boards into final game screens.
