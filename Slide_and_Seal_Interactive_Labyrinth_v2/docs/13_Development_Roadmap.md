# 13 — Development Roadmap

Quality-first planning envelope: approximately 20–24 weeks for a solo developer, depending on art production, mechanic complexity and playtesting. This is not a fixed deadline.

| Phase | Indicative duration | Exit deliverable |
|---|---:|---|
| Design lock and prototype rules | 1–2 weeks | Rule decisions and acceptance tests |
| Simulation foundation | 2–3 weeks | Grid state, actions, collision |
| First 3D vertical slice | 2–3 weeks | One beautiful playable level |
| Gravity and push | 2 weeks | Tested mechanics |
| Core travel and checkpoints | 1–2 weeks | Run/pause/resume |
| Portals and switches | 2 weeks | Connected system prototype |
| Rotation, energy, polarity | 3–4 weeks | Experimental mechanics validated |
| Solver and content pipeline | 2–3 weeks | Validated level workflow |
| Campaign and daily content | 3–4 weeks | 50 campaign + daily schedule |
| UI, audio and polish | 2–3 weeks | Feature-complete game |
| Monetization and QA | 2–3 weeks | Release candidate |

## Milestone acceptance

### M1 — Simulation proof
Headless simulation applies deterministic actions without a scene tree.

### M2 — First vertical slice
One level with 3D board, core travel, checkpoint, gravity and push.

### M3 — Mechanic foundation
Portal, switch/gate, rotation, energy routing and polarity rules validated individually.

### M4 — Solver/content pipeline
Level schema, validator, solver and editor workflow usable.

### M5 — Feature complete
Campaign, Daily Puzzle, save, UI and settings.

### M6 — Commercial readiness
Billing/ads test track, privacy review and analytics.

### M7 — Release candidate
Device QA, performance, store assets and release checklist.
