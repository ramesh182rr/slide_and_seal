# 17 — Product Add-on Suggestions

These are recommendations, not all mandatory version 1.0 features.

## Strong candidates for version 1.0
1. **Mechanism Preview:** show the expected result before committing an action.
2. **Mechanism Replay:** replay the completed solution sequence.
3. **World Discovery:** subtle environmental storytelling through seven worlds.
4. **Puzzle Journal:** best action count, stars and replay.
5. **Reduced-motion and accessibility presets.**

## Post-launch candidates
- Daily puzzle archive.
- Cosmetic core skins.
- Environment theme packs.
- Optional challenge objectives.
- Community level sharing.
- Level editor.
- Cloud saves.
- Additional worlds and mechanic packs.

## Prioritization rule

Every feature must improve clarity, puzzle depth, accessibility, replayability or sustainable commercial value. Do not add a feature just because it looks impressive.
