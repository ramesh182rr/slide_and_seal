## Level authoring rule

The title and brief are not sufficient for release. Each level needs:
- Complete JSON data.
- Mechanic rules used.
- Checkpoint placement.
- Objective.
- Validated solution.
- Target action count.
- Human playtest notes.
- Visual layout reference.
